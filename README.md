# HTML-CSS-JavaScript – Nybörjarkurs

Material till en praktisk nybörjarkurs i webbutveckling. Deltagare bygger en enkel, komplett webbplats och lär sig grundläggande **HTML**, **CSS** och **JavaScript**.

**Demo:** https://delzarkafashi.github.io/HTML-CSS-JavaScript-Nyborjarkurs/

## Innehåll
- `Lektion 1–6/` – lektionsmappar med övningar och uppgifter  
- `bilder/` – bilder som används i exemplen  
- `index.html`, `kontakt.html`, `projekt.html`, `style.css` – demosidor

## Kom igång
1. Ladda ner eller klona repot.  
2. Öppna `index.html` i din webbläsare. (Ingen build krävs.)
